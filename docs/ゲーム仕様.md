# ゲーム仕様

> 数値はすべて **初期値**。遊んでみて調整する前提で、コード側では1か所（`src/data/balance.js`）にまとめる。
> 依頼文にない部分はこちらで決めた案で、`【案】` を付けている。

---

## 1. コンセプト

- 主人公：三毛猫の **てらまる**
- 目的：90秒のあいだに、街の「ターゲット」の足元をぐるぐる回って（てらまりんぐ）メロメロにし、ポイントを貯めて「おねだり」し、構ってもらってスコアを稼ぐ
- 見た目：ドット絵、横スクロールではなく **見下ろし型（斜め上から）** の街を自由に歩く

## 2. 用語

| 用語 | 意味 |
|---|---|
| ターゲット | てらまりんぐの相手。人・ロボット・動物・ランドマーク |
| てらまりんぐ | ターゲットの足の周りをぐるぐる回ること。ミニゲームになる |
| メロメロ | てらまりんぐ成功の状態。ハートが出る |
| てらまりんぐポイント（TP） | てらまりんぐ成功で貯まる。おねだりで消費する（依頼文の「てらまるポイント」も同じものとして扱う） |
| おねだりアタック | TPを消費して構ってもらう抽選に挑むモード |
| 構ってもらう | なでなで・おもちゃ・追いかけっこ。スコアと残り時間が増える |
| ご飯ポイント（FP） | ご飯や水で増える。「おなか」がたまり、20でいっぱい |
| 総合スコア | プレイの成績。1%がてらまるコイン |
| てらまるコイン | 買い物（ショップ）に使える通貨。プレイをまたいで貯まる |

## 3. 画面の流れ

```
タイトル ─→ ステージ選択 ─→ プレイ ──→ リザルト ─→ タイトル
   │                          │  ↑
   ├→ ショップ（将来）          ├→ てらまりんぐ（ズームイン）
   ├→ アーカイブ（将来）        ├→ 構ってもらう演出
   └→ 遊び方                   └→ ポーズ（いつでも）
```

| 画面 | 内容 |
|---|---|
| タイトル | ロゴ、てらまる、所持コイン、「はじめる」「遊び方」「ショップ」「アーカイブ」 |
| ステージ選択 | 解放済みステージを選ぶ（§10） |
| プレイ | 街を歩く。上部にHUD（§9） |
| てらまりんぐ | ターゲットに触れると足元へズームイン（§5） |
| 構ってもらう | おねだり成功時の短い演出（§6） |
| ポーズ | 再開／最初から／遊び方／タイトルへ |
| リザルト | スコアの内訳、総合スコア、獲得コイン、ベスト更新表示 |

## 4. 操作

3種類の入力を同時に受け付け、どれで遊んでもよい。

| 操作 | キーボード | マウス | タッチ |
|---|---|---|---|
| 移動 | WASD／矢印キー（斜めも可） | てらまる以外の場所で左ボタンを押している間、カーソルの方へ歩く | てらまる以外の場所をドラッグ → その場にバーチャルスティックが出る |
| おねだりアタック | 決定キー長押し＋方向キーで狙う → 離して発動 | てらまるを押さえてターゲットの方へドラッグ → 離して発動 | てらまるを押さえてターゲットの方へスライド → 離して発動 |
| 決定 | Enter／Space | 画面上の［決定］ボタンをクリック | 右下の［決定］ボタン |
| ポーズ | Esc／P | 右上の［ポーズ］ | 右上の［ポーズ］ |
| メニュー選択 | 上下キー＋決定 | クリック | タップ |

- 押した場所がてらまるの上（指で押しやすいよう見た目より広め）なら「おねだり照準」、それ以外なら「移動」として扱う
- キーボードの決定キーは、爪とぎスポットの近くでは爪とぎ、それ以外では長押しでおねだり照準

**決定ボタンの使いみち（プレイ中）**

- 爪とぎスポットの近く → 爪とぎ
- 押せるときはボタンが光り、何が起きるかのアイコンを表示する

**自動ポーズ** 【案】：タブを切り替えた・スマホで別アプリに移ったときは自動でポーズ。

**スマホ**：横向きで遊ぶ。縦向きのときは「よこにしてね」と表示して止める。

## 5. てらまりんぐ（メインのミニゲーム）

### 5.1 流れ

1. 街でてらまるがターゲットに接触する
2. カメラがターゲットの足元へズームイン（0.4秒）
3. 真上から見た足元の画面になる。足（靴・脚・車輪・柱など）が並んでいる
4. てらまるを動かして、足の周りをぐるぐる回る
5. **すべての足を最低1周** し、かつ **メロメロゲージが満タン** になったら成功
6. 成功：ハートがパーッと出て、TP獲得。ご飯を持っていればターゲットの近くにご飯が軽く散らばり、**ハートと一緒にてらまるへ吸い込まれる**（§7.1） → ズームアウトして街へ戻る

- **てらまりんぐ1回ごとの制限時間はない**。ただしその間もプレイの残り時間は減り続けるので、手こずるほど損をする
- やめたいとき：画面の端まで歩いて出ると街へ戻る（ゲージはなくなり、そのターゲットには15秒近づけない）【案】

### 5.2 判定

- 足ごとに「てらまるが足の周りを何度回ったか」を角度の合計で数える（360°で1周）
- 足から一定の距離の輪（近すぎず遠すぎず）の中にいるときだけ数える
- 1周ごとにメロメロゲージが増える。ゲージの最大値 ＝ **メロメロ耐久度**
- 動く足にぶつかると、てらまるがよろけて0.5秒止まり、ゲージが少し減る
- 8の字（2本の足の間をくぐって回る）は両方の足の周回として数えられるので、うまい人ほど早い

### 5.3 ターゲットによって変わるもの

| 要素 | 影響 |
|---|---|
| 足の本数 | 全部回る必要があるので多いほど大変 |
| 足の動き | 棒立ち／足踏み／歩き回る／規則的に動く／激しく動く。動くほど回りにくく、ぶつかりやすい |
| メロメロ耐久度 | 必要な周回数。高いほど時間がかかる |
| TP | 本数・動き・耐久度が大きいほど高い。最低2 |
| 落とすもの | ご飯（食べられる）や、将来のコレクション用アイテム |

## 6. おねだりアタック と 構ってもらう

てらまりんぐ（ぶつかって始まる）とは操作を分け、**画面上のてらまるを触って、ターゲットへスライドして発動** する。

### 6.1 流れ

1. TPが **10以上** のとき、画面上のてらまるを押さえる（タッチ／マウスの左ボタン）。10未満のときは押さえても照準にならず、TPの横に「あと○」と出す
2. 押さえている間は **照準中**
   - てらまるの周り（半径およそ画面の1/3）にいる、おねだりできるターゲットの頭上に **成功確率（%）** を表示する
   - 指／カーソルの向きに矢印が伸び、いま狙っているターゲットが点滅する
   - 照準中は **街が止まる**。キャラはその場でぴこぴこ動く（足踏み・体を揺らす程度）だけで位置は変わらない
   - 照準中は **残り時間を消費しない**（お水・爪とぎ・トイレの残り時間も止まる）
3. ターゲットの方へスライドして指を離すと **発動**：てらまるがそのターゲットへ飛びつき、抽選
   - 発動した時点で **持っているTPをすべて消費** する（失敗しても戻らない）
   - ターゲットのいない方向で離した・てらまるの上で離したときは何も起きず、TPも減らない
4. 成功 → 構ってもらう演出へ。失敗 → ターゲットが「また今度ね」と去る

**キーボードの場合**：決定キーを押している間が照準中。方向キーで狙うターゲットを切り替え、決定キーを離すと発動。

おねだりできるのは「人」と「動物」。ロボットとランドマークは照準中に「×」と表示する 【案】。

### 6.2 成功確率

ターゲットごとに「基本の確率」と「TPが1増えるごとの上がり幅」を決め、**持っているTPが多いほど全ターゲットの確率が上がる**。100%で頭打ち（100%もありうる）。

`成功確率 = 基本 + 持っているTP × 上がり幅`（上限100%）

| ターゲット | 基本 | 上がり幅 | TP20 | TP50 | TP100% になるTP |
|---|---|---|---|---|---|
| 棒立ちの会社員 | 40% | 1.0% | 60% | 90% | 60 |
| パン屋さん・魚屋さん・お肉屋さん | 30% | 0.9% | 48% | 75% | 78 |
| 八百屋さん | 35% | 1.0% | 55% | 85% | 65 |
| 杖のおばあちゃん | 35% | 1.0% | 55% | 85% | 65 |
| 元気な子ども | 20% | 0.8% | 36% | 60% | 100 |
| 散歩中の犬 | 15% | 0.7% | 29% | 50% | 122 |
| 鳩の群れ | 5% | 0.6% | 17% | 35% | 159 |
| 馬（観光馬車） | 10% | 0.6% | 22% | 40% | 150 |

- 狙いやすい相手ほど、構ってもらう内容は控えめ（§6.3）
- 確率の表示は整数%。100%のときは金色で表示 【案】

### 6.3 構ってもらう内容

TPが多いほど良い内容が出やすい。演出中はタイマーが止まる。

※ おなか（§7.4）との関係は未定（体重の列は旧案。あとで決める）

| 内容 | 出やすいTP | スコア | 時間延長 | 体重 | 演出 |
|---|---|---|---|---|---|
| なでなで | 20〜 | +300 | +3秒 | −5 | 手でなでられる（2秒） |
| おもちゃで遊ぶ | 50〜 | +600 | +5秒 | −15 | 猫じゃらしにパンチ。連打でスコア少し上乗せ（4秒） |
| 追いかけっこ | 90〜 | +1000 | +8秒 | −30 | 相手を追いかけるミニゲーム。捕まえたらボーナス（5秒） |

内容の重み 【案】：消費したTPが 10〜49 は なでなで100%、50〜89 は なでなで60%・おもちゃ40%、90以上は なでなで30%・おもちゃ40%・追いかけっこ30%。
さらに、成功確率の低い相手（基本20%未満：犬・鳩・馬）は一段良い内容になりやすい（なでなで→おもちゃ、おもちゃ→追いかけっこへ、30%の確率で格上げ）。

## 7. 街の中の要素

### 7.1 ご飯

- ご飯を持っているターゲットにてらまりんぐ成功すると、ターゲットの近くにご飯がポロポロ軽く散らばる
- 散らばったご飯は、ハートと一緒にてらまるへ吸い込まれる（拾いに行かなくてよい）：**1個につきご飯ポイント+2**
- 演出：散らばる 0.3秒 → ハートとご飯がてらまるへ吸い込まれる 0.6秒。1個吸い込むごとに「+2」がポンと出る
- 個数はターゲットごと（§5.4 の「落とすもの」）

### 7.2 爪とぎ

- 街の爪とぎスポット（電柱・木・段ボール）に触れると、**勝手に** 1秒の爪とぎモーション（水と同じ。ボーナス中・直後4秒はしない）
- そこから **8秒以内に「人」に触れれば**、そのてらまりんぐは成功時に **TPが2倍**（成功までにかかる時間は問わない）
- 残り時間はHUDに爪マークで表示

### 7.3 お水

- 水飲み場（水皿・噴水・水たまり）に触れると水を飲む
  - かかる時間は **0秒**（触れた瞬間に回復）
  - **ご飯ポイント+1**
- 最後に水を飲んでから **25秒** 経つと倒れる（**てらまりんぐ中は数えない**）
  - 18秒で警告（HUDの水マークが点滅、てらまるに汗マーク）
- 倒れると：人に抱えられて病院へ運ばれる演出
  - **復帰まで5秒**（その間もタイマーは進む＝ペナルティ）
  - 復帰地点はステージの **病院**
  - おねだり中・爪とぎボーナス・トイレ中の効果は消える。TPとご飯ポイントは残る 【案】

### 7.4 おなか（いっぱいで重くなる）

- おなかゲージ 0〜20（人1人でご飯6〜10なので、2〜3人でいっぱい）。ご飯ポイントを得るとその分たまる（スコア用の合計はいっぱいでも増える）
- 段階と影響：

| おなか | 見た目 | 移動速度 | てらまりんぐへの影響 |
|---|---|---|---|
| 0〜11 | ふつう | 100% | なし |
| 12〜19 | ぽっちゃり（少し横に広がる） | 85% | 小回りがきかない（曲がりにくい） |
| 20（いっぱい） | がまん中（もじもじ） | 70%。いっぱいのあと食べるたびに遅くなり、さらにご飯20で50% | さらに曲がりにくく、ぶつかったときのよろけが長い |

- いっぱいになると「もじもじ…」。HUDのおなかが赤く点滅し、街の猫砂の上に「トイレ」の矢印、画面の外なら端に猫砂のマーク
- いっぱいのままでも時間切れや罰はない（吐くなどはしない）。トイレに行かずに食べ続けると、食べるたびに遅くなる

### 7.5 猫砂でトイレ → トイレフィーバー

- いっぱいのときに猫砂に触れると、自動で「カキカキ」（1.5秒、砂が飛ぶ）→「すっきり！」。おなかは0に戻る
- その後 **10秒間**：移動速度1.5倍、ターゲットに触れるだけで **自動でてらまりんぐ成功**（ミニゲームなし）
- 自動成功でもTP・ご飯・爪とぎ2倍はふつうどおり付く 【案】
- 始まりに「トイレフィーバー！」を大きく出し、時計の下に残り時間のバー、てらまるのまわりはキラキラ

### 7.6 ほかの猫（てらまるは猫嫌い）

てらまるは猫が苦手。ステージ2以降、街にほかの猫（野良猫・飼い猫）が出てくる。

- 猫のまわり（半径 約2マス）は **ニガテゾーン**。てらまるは入れない（近づくと押し戻され、「シャー」と毛を逆立てる）【案】
- ニガテゾーンの中にいるターゲットには **てらまりんぐもおねだりもできない**
  - おねだりの照準中は、そのターゲットに成功確率のかわりに「×」を出す
  - てらまりんぐ中に猫が近づいてきたら、そこで中断（失敗扱いではなく、やり直せる）【案】
- 猫はゆっくり歩き回ったり、ターゲットの近くで座り込んだりして、じゃまをする
- ステージが上がるほど猫が増える・動きが速くなる 【案】
- 猫はターゲットにはならない（てらまりんぐ・おねだり不可）

## 8. スコアとコイン

### 8.1 総合スコア

| 内訳 | 計算 |
|---|---|
| てらまりんぐ | 獲得したTPの合計 × 10（消費しても減らない） |
| ご飯 | 獲得したご飯ポイントの合計 × 5 |
| 構ってもらった | §6.3 のスコアの合計 |
| ノーミスボーナス | 一度も倒れなかったら +500 |

目安：ふつうに遊んで 3,000〜8,000点（コイン30〜80枚）。

### 8.2 てらまるコイン

- `獲得コイン = 総合スコア × 1%（端数切り捨て）`
- いまは端末（ブラウザ）に保存して、プレイをまたいで貯まる。将来ログインを付けて端末間で共有できるよう、保存の部分は差し替えやすく作る
- 使いみち（将来）：ショップで首輪・帽子などの見た目、ステージの解放など

### 8.3 将来の要素（今回は枠だけ作る）

- **ショップ**：コインで買えるもの
- **アーカイブ**：コインでは買えないもの（条件達成で解放）、読み物（てらまるの日記・ターゲット図鑑など）
- 「ネジ」など食べられない落とし物はアーカイブの収集アイテムにする想定

## 10. ステージ

1プレイ＝1ステージ。リザルトのスコアが一定以上だと次のステージが解放される。

| # | ステージ | 主なターゲット | 解放条件 |
|---|---|---|---|
| 1 | 商店街 | 人（会社員・パン屋・魚屋・お肉屋・八百屋・子ども・おばあちゃん） | 最初から |
| 2 | 公園 | ＋犬・鳩・ベンチ（ほかの猫が出はじめる §7.6） | ステージ1で3,000点 |

## 11. てらまるの見た目

写真から決めた模様：

| 部位 | 模様 |
|---|---|
| 顔 | 正面から見て **左半分が黒**（目の周りから耳まで）、**右半分は目の上が茶で、その外側が黒**。額から鼻筋は **白い筋** |
| 耳 | 左耳は黒、右耳は黒地に付け根が茶。耳の内側はピンク |
| 口元 | 白地に、鼻の下の左右に **小さな茶のぶち**（ひげ模様のよう） |
| 鼻・肉球 | ピンク |
| 目 | **左右で色が違う（オッドアイ）**。てらまるの右目（正面から見て左）が **茶**、左目（正面から見て右）が **黄緑**。横向きの絵では見えている側の目の色にする |
| 首・胸・お腹・4本の足 | 白 |
| 背中・腰 | 茶に **黒い縞・ぶち**（背骨に沿って太い黒、わき腹に細い黒） |
| しっぽ | 茶に黒の縞、先が黒っぽい。ふさっと太め |
| 体形 | 丸みのあるがっしり体形（太るとさらに丸く） |

- 色（案）：白 `#F4F1EA`／茶 `#C8823A`（影 `#9A5A24`）／黒 `#2A2420`／ピンク `#E8A0A0`／右目 茶 `#8A5A2A`／左目 黄緑 `#B8C840`
- サイズ：街では16×16ドット、てらまりんぐ画面では24×24ドット
- アニメーション：待機・歩き（4方向）・てらまりんぐ（尻尾ピーン）・爪とぎ・水飲み・食べる・倒れる・トイレ・メロメロにされる側のハート

## 12. 文字

- **画面の文字はすべてドット文字**（タイトル・HUD・メニュー・ボタン・リザルト・セリフ）
- 日本語は無料で使えるドットフォントを使う：
  - 小さい文字（HUDの数字・ラベル）：**美咲フォント**（8×8ドット）
  - 読む文字（遊び方・セリフ・アーカイブの読み物）：**k8x12**（8×12ドット、漢字あり）
  - タイトルロゴは手描きのドット
- ボタンも画面（キャンバス）に描くので、ボタンの文字もドット

## 13. 音 【案】

- 外部の素材は使わず、ブラウザ内でピコピコ音（チップチューン風）を作る
- 効果音：足音、周回1回、メロメロ成功、ご飯を食べる、水、爪とぎ、警告、倒れる、おねだり成功／失敗
- BGM：ステージごとに短いループ
- ミュートボタンあり。スマホは最初のタップまで音が出ない（ブラウザの仕様）
