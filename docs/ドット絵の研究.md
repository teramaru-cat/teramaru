# ドット絵の研究レポート

てらまるゲームの絵を描くときの決まりごとをまとめる。ドット絵の講座・用語集・論文などを読んでまとめたものと、それを踏まえて今のゲームの絵を見直した結果。

---

## 1. ドット絵の基本の考え方

ドット絵は「小さい絵を大きくしたもの」ではなく、**1ドットずつ意味を持たせて置く絵**。描くときに気をつける点は、だいたい次の4つにまとまる。

1. **シルエット**：黒く塗りつぶしても何かわかる形にする。いちばん先に決める。
2. **線（ジャギ・ダブル）**：線や曲線の段差を規則正しくする。
3. **かたまり（クラスター）**：同じ色を、まとまったかたまりで置く。
4. **色**：色の数をしぼり、となりあう色がはっきり見分けられるようにする。

台湾の入門書でも、ドット絵の三要素を「簡略化・シルエット・色」とし、とくに簡略化とシルエットが大事だとしている。

---

## 2. 線のきまり

### 2.1 きれいな直線（パーフェクトライン）
- 段の長さがそろっている直線は、目がなめらかにたどれる。
- 0:1（水平・垂直）、1:1（45°）、1:2、2:1、1:3 などの整数の比を使う。
- 段の長さがばらばらな直線（2,1,3,1…）はガタガタに見える。

### 2.2 なめらかな曲線
- 段の長さを**少しずつ**変える。たとえば 5,2,2,1,1 のように、長い段から短い段へなだらかに減らす。
- 5,2,1,2,1 のように行ったり来たりすると、線の途中に「こぶ」ができる。
- 円は、てっぺんの長い段から 3,2,1,1,2,3 のように、左右対称に減らして増やす。

### 2.3 ジャギとダブル
- **ジャギ**：段差の長さがそろわず、ギザギザして見えるところ。
- **ダブル**：線に余分な1ドットがあって直角の角ができ、線が太って見えるところ。
- どちらも仕上げで1ドットずつ消して直す。

---

## 3. かたまり（クラスター）とノイズ

- **ひとりぼっちのドット（孤立ドット）**は「ざらつき（ノイズ）」になり、何を見ているのか目が迷う。
- 同じ色はできるだけ大きなかたまりにまとめる。
- 1ドットだけで置くのは、意味があるとき（目の光・ボタンなど）だけにする。

---

## 4. 色

- 小さいキャラクターは**少ない色**で足りる（1キャラ数色〜十数色）。
- となりあう色は、等倍で見てはっきり区別できるようにする。
  - 肌と髪、肌と服の色は離す。
  - 肌が明るいなら目は黒くするなど、**顔は明暗の差を大きく**する。
- 影をつける場合は、ただ暗くするのではなく、色あい（色相）も少しずらす（ヒューシフト）。
  - **てらまるゲームでは立体の影はつけない**（§7）。

---

## 5. やってはいけない影：ピロー・シェーディングとバンディング

- **ピロー・シェーディング**：ふちに沿って明るい・暗いの帯をぐるっと入れる塗り方。
  - 光の向きと関係ないので、クッションのように膨らんで安っぽく見える。
  - 初心者がいちばんやりがちな失敗とされる。
- **バンディング**：色の帯の端がそろって並び、段々に見えること。ピロー・シェーディングはその重いもの。
- 前回のかまって画面の「色のかたまりごとに、ふちを明るく・暗くする」処理は、まさにピロー・シェーディングだった。**やめる**。

---

## 6. 大きさをまぜない（ミクセル）

- 1つの画面の中に、**大きさのちがうドット**（3倍にした絵と等倍の絵など）がまざることを「ミクセル」という。
  - ちぐはぐに見え、手抜きに見えやすい。
- 対策は、画面ごとにドットの大きさを1つにそろえること。
  - 1.5倍・2.5倍のような半端な拡大は、ドットの幅がばらばらになるので使わない。
  - 拡大は整数倍で、ぼかさずに（最近傍で）行う。
- アンチエイリアス付きのベクター線（キャンバスの stroke）も、ドットの格子から外れるので、ドット絵の中では浮く。

---

## 7. てらまるゲームの絵のきまり

ここまでを踏まえて、このゲームでは次のようにする。

| きまり | 内容 |
|---|---|
| 立体の影はつけない | 色は面ごとに1色（ベタ塗り）。明るい・暗いの帯は入れない（ピロー・シェーディング禁止） |
| ふちは1ドット | 外がわは `INK`（こげ茶）1ドット。内がわの線は形を見せるのに必要なところだけ（腕と体のさかい、足のあいだなど） |
| 画面ごとにドットの大きさをそろえる | 1つの画面の中で、3倍の絵と等倍の絵をまぜない |
| 大きく見せたい絵は、その大きさで描き直す | 小さい絵を拡大して細工するのではなく、大きい絵を1ドットずつ描く |
| 線は段をそろえる | 曲線は段の長さを少しずつ変える。左右対称の顔・体は半分を描いて反転する |
| 顔は明暗をはっきり | 肌は明るく、目は `INK` の黒。光は1ドット。ほっぺはうすいピンク |
| 笑顔は目で | 口を大きくあけると血や怖い顔に見えるので、笑顔は「^ ^」の目と小さい口で表す |
| 孤立ドットを作らない | 1ドットで置くのは目の光・ボタン・ほっぺなど、意味のあるものだけ |

## 8. 今のゲームの見直し

### 8.1 かまって画面（なでなで・おもちゃ・おいかけっこ）

**前の版の問題**
- 小さい人（14×29）を3倍にして、その上に細かい顔を描き足していた。
  - 体は3ドット単位、顔は1ドット単位で、ミクセルになっていた。
- ふちに沿って明るい・暗いの帯を入れていて、ピロー・シェーディングになっていた。
- 腕がアンチエイリアス付きのベクター線で、ドットの格子から浮いていた。
- てらまるは3倍の絵で、人は等倍の絵になり、大きさがまざっていた。

**直したこと**
- 人を、かまって画面の大きさ（等倍）で1ドットずつ描く。
  - 顔・髪・体・服の形を半分ずつの文字の表で描き、左右を反転して対称にする。
  - ベタ塗りで、ふちは1ドット。
- 腕・おもちゃのひもも1ドットの格子にそって描く（ベクター線をやめる）。なでられて頭が下がる動きも、絵をちぢめずに1ドットずらす。
- てらまるも、同じ大きさのドットで描き直す。

### 8.2 これから気をつけること
- 新しい絵を足すときは、まず等倍で見て読めるかを確かめる。
- 拡大した画面（てらまりんぐ画面の2倍など）は、その画面の中のドットの大きさを全部そろえる。
