# てらまる 〜てらまりんぐ大作戦〜

うちの三毛猫「てらまる」が主人公の、ドット絵のブラウザゲーム。
てらまるが街を歩き回り、人やロボット、動物、ランドマークの足元をうろちょろして（＝**てらまりんぐ**）メロメロにし、構ってもらってスコアを稼ぐ。

- 1回のプレイは **90秒**（構ってもらうと延びる）
- 終わったら **総合スコア** を表示し、その **1%** が **てらまるコイン** になる
- PC（キーボード・マウス）でもスマホ（タッチ）でも遊べる
- スマホは横向きで遊ぶ。iPhone は Safari の共有ボタン →「ホーム画面に追加」で、アドレスバーのない全画面になる。Android は最初のタップで全画面・横向き固定になる

## エリアとステージを変えるとき

- ステージの並び・出てくる人と人数・使えるしくみ（お水・ご飯・フィーバーなど）・開く条件：[src/data/areas.js](src/data/areas.js) の表だけを書きかえる
- チュートリアル（0-1）の流れとセリフ：[src/game/tutorial.js](src/game/tutorial.js)。ウィルキャッ（キラキラの声）の名前と枠：[src/game/voice.js](src/game/voice.js)
- 街の地図：[src/data/maps/](src/data/maps/) にステージごとのファイル（新しいステージは地図を作って areas.js の `map` に入れる。`map: null` のあいだは「じゅんびちゅう」）
- ターゲット（人・動物・ベンチ）：[src/data/targets.js](src/data/targets.js) の表。強さ・落とすご飯・動き・足の位置・見た目・おねだりの確率に加えて、おねだりできるか・爪とぎ2倍が効くか・去るか・メロメロのときの言葉・構ってもらうときの言葉も、ここで1人ずつ決める（種類ごとのふつうの値は同じファイルの KINDS）。絵の形そのものは art/people.js（人）と art/animals.js（動物・ベンチ）
- 数値の調整：[src/data/balance.js](src/data/balance.js)

## 動かし方

```sh
cd ~/Desktop/てらまるゲーム
python3 serve.py
# ブラウザで http://localhost:8123 を開く
# 当たり判定などを見たいときは http://localhost:8123/?debug=1
#   （debug中のキー：T 残り5秒 / F ご飯+30 / H お水切れ寸前 / G おなかいっぱい / K TP+30）
```

スマホで試すときは、同じWi-Fiにつないで `http://<MacのIPアドレス>:8123` を開く。

`serve.py` はブラウザに古いファイルを使わせない設定のサーバー（`python3 -m http.server` だと、直したのに古い画面のままになることがある）。
