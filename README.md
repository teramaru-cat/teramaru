# てらまる 〜てらまりんぐ大作戦〜

うちの三毛猫「てらまる」が主人公の、ドット絵のブラウザゲーム。
てらまるが街を歩き回り、人やロボット、動物、ランドマークの足元をうろちょろして（＝**てらまりんぐ**）メロメロにし、構ってもらってスコアを稼ぐ。

- 1回のプレイは **90秒**（構ってもらうと延びる）
- 終わったら **総合スコア** を表示し、その **1%** が **てらまるコイン** になる
- PC（キーボード・マウス）でもスマホ（タッチ）でも遊べる

## 動かし方

```sh
cd ~/Desktop/てらまるゲーム
python3 serve.py
# ブラウザで http://localhost:8123 を開く
# 当たり判定などを見たいときは http://localhost:8123/?debug=1
```

スマホで試すときは、同じWi-Fiにつないで `http://<MacのIPアドレス>:8123` を開く。

`serve.py` はブラウザに古いファイルを使わせない設定のサーバー（`python3 -m http.server` だと、直したのに古い画面のままになることがある）。
